# Auto Front Matter

Auto Front Matter adds an `Auto: front matter` action to eligible Markdown files in the Obsidian file tree. It sends note content, vault-relative path context, existing tags, and current frontmatter to an AI provider, then applies generated filename, tags, description, and configured custom properties.

## Settings

- API base URL
- API key
- Model
- API type
- Naming style
- Description language
- Content mode
- First-lines limit
- Tag policy
- Max generated tags
- Tag context limit
- Tag write mode
- Custom properties
- Excluded paths

Excluded path rules support plain folder prefixes, JavaScript-style regular expressions, and `regex:` rules.
