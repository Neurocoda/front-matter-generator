# Contributing

Thanks for helping improve Front Matter Generator.

## Development

```bash
npm install
npm test
npm run lint
npm run build
npm run check-release
```

`main.js` is generated by esbuild and intentionally ignored by Git. Build it locally before testing a release package.

## Repository Shape

The plugin repository root contains the Obsidian release files and source:

- `manifest.json`
- `versions.json`
- `package.json`
- `package-lock.json`
- `README.md`
- `LICENSE`
- `src/`
- `tests/`
- `styles.css`

Do not commit `data.json`, `node_modules/`, generated `main.js`, logs, caches, or sourcemaps.

## Release

1. Update `manifest.json`, `package.json`, `package-lock.json`, and `versions.json`.
2. Run `npm test`, `npm run lint`, `npm run build`, and `npm run check-release`.
3. Commit the release changes.
4. Create an annotated tag that exactly matches `manifest.version`, for example `git tag -a 1.1.0 -m "Release 1.1.0"`.
5. Push `main` and the tag.
6. Review the draft GitHub release created by the release workflow.

Required release assets are:

- `main.js`
- `manifest.json`
- `styles.css`
